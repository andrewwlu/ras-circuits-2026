## Ras Circuits 2026
- Data and analysis for "Engineered protein circuits for cancer therapy"
- Data and R scripts are organized by figure in `figures/fig1/`, `figures/fig2/`..etc
- Each fig has a matching `_data.csv` and `_plot.R` file

## Requirements
- R with **ggplot2** and its dependencies (`scales`, `gtable`, and the R `grid` package)
- Tested with R 4.5.2 and ggplot2 4.0.2.
